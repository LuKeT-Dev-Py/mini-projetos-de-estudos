# Mini projetos de estudos

Repositório de João Antônio (LuKeT-Dev-Py) para reunir mini projetos desenvolvidos durante o estudo de Python. Cada projeto fica em uma pasta própria, com código, README, exemplos de uso e limitações documentadas.

## Projetos

| Projeto | Objetivo | Conhecimentos aplicados |
|---|---|---|
| [Registro de Estudos](registro-de-estudos/) | Registrar sessões e consultar o total de minutos estudados | Listas, dicionários, funções, módulos, validações e laços |

## Como executar

Consulte o README da pasta do projeto para os requisitos e comandos. Para o Registro de Estudos:

```bash
cd registro-de-estudos
python3 main.py
```

## Organização

- Uma pasta para cada mini projeto.
- O README de cada projeto descreve o que está implementado e separa limitações de próximos passos.
- Novos mini projetos serão acrescentados ao índice conforme forem concluídos e conferidos.

Estes programas são projetos de aprendizado. As funcionalidades e os resultados de verificação estão documentados em suas respectivas pastas.
